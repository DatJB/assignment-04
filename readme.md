
# Assignment 04 - Convolutional Neural Network

## Nội dung

Bài tập thực nghiệm CNN trên 3 bộ dữ liệu:

- MNIST
- Fashion-MNIST
- UCI Digits

Mỗi bộ dữ liệu được triển khai theo 3 cách:

- CNN From Scratch bằng NumPy
- CNN bằng TensorFlow/Keras
- CNN bằng PyTorch

Ngoài ra có:

- Biểu đồ Accuracy
- Confusion Matrix
- So sánh kết quả giữa các cách cài đặt
- Giải thích các hàm chính được sử dụng
